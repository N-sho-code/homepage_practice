| ファイル              | 画面あり/なし | 主な役割                                |
| ----------------- | ------- | ----------------------------------- |
| index.php         | 画面あり    | クイズ開始画面、フォーム送信（→quiz.php）           |
| **questions.php** | 画面なし    | クイズ問題データの配列を保持、他ファイルから読み込まれる        |
| quiz.php          | 画面あり    | 問題表示、回答受付、スコア加算、次の問題へまたはresult.phpへ |
| result.php        | 画面あり    | 最終スコア表示、`questions.php` を使って満点など算出  |


┌────────────┐
│ index.php │  ← スタート画面（「クイズを始める」）
└────┬───────┘
     │ POST（submit）
     ▼
┌────────────┐
│  quiz.php  │  ← クイズ出題・回答処理
│  ↑        │
│  └─┬──────┐
│    │ require 'questions.php'
│    ▼
│ ┌────────────────────┐
│ │  questions.php     │ ← クイズデータ保持（配列）
│ └────────────────────┘
└────┬───────┘
     ▼
┌────────────┐
│ result.php │  ← 回答結果を表示
│     ↑      │
│     └──────┐
│            ▼
│ ┌────────────────────┐
│ │  questions.php     │ ← 得点計算に使う
│ └────────────────────┘
└────────────┘
