# homepage_practice
## 目的  
自身の学習成果や開発経験をまとめ、
就職活動で自分のスキルや成長をわかりやすく伝えるために作成しました。  

## 工夫したこと  
・初めて見る人でも迷わないように、シンプルで見やすいレイアウトを心がけました。  
・スマホでも見やすくなるよう、レスポンシブ対応とハンバーガーメニューを取り入れました。  
・制作物が増えても見やすいように、カテゴリ別に絞り込みができるフィルター機能をつけてみました。  
・あとから内容を増やしやすいように、HTMLの構造も整理して書くことを意識しました。
